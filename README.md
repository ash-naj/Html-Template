# Landing Page Template

A clean, zero-dependency landing page template built from scratch with semantic HTML5 and vanilla CSS3. Designed as a reusable starting skeleton for static websites and GitHub Pages deployments.

---

## Features

- **Zero Dependencies:** Pure HTML and CSS—no build tools, frameworks, or external libraries required.
- **Two-Box Layout Architecture:** Full-width background color bands paired with centered `1000px` max-width content containers.
- **100% Flexbox:** Responsive alignment across the navigation bar, split hero section, 4-card showcase, quote block, CTA banner, and sticky footer.
- **One-Click Theming:** Global CSS custom properties (`:root`) for instant color scheme swaps.
- **Sticky Footer:** Uses `min-height: 100vh` and `margin-top: auto` so the footer stays pinned to the bottom edge on tall viewports.
